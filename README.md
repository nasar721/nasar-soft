# ناصر سوفت | Nasser Soft

تطبيق ويب عربي لإدارة العمليات اليومية للمنشآت الصغيرة، مع واجهة عربية واتجاه عرض من اليمين إلى اليسار.

## الوحدات الموجودة

- لوحة معلومات والقيود المحاسبية.
- فواتير المبيعات والمشتريات.
- إدارة المخزون والمستودعات.
- العملاء والموردون والموظفون.
- التقارير المالية وتقارير المخزون.
- إعدادات المنشأة والفواتير.
- نسخ احتياطي محلي واستعادة البيانات وتصدير الفواتير إلى CSV.
- دعم التثبيت كتطبيق ويب (PWA) مع تخزين مؤقت لغلاف التطبيق.

## تحسينات السلامة المحاسبية

- إضافة حسابات مراقبة مستقلة للذمم المدينة والدائنة.
- تسجيل المتبقي على العميل ضمن الذمم المدينة والمتبقي للمورد ضمن الذمم الدائنة.
- فحص المخزون قبل اعتماد فاتورة البيع.
- التحقق من الكمية والسعر والخصم والضريبة والمبلغ المدفوع قبل حفظ الفاتورة.

## التقنيات والتشغيل

React 19 وTypeScript وVite وHeroicons وRecharts.

يتطلب التشغيل Node.js وnpm:

```bash
npm install
npm run dev
npm run build
npm run preview
```

## التخزين والعمل دون اتصال

- تُحفظ بيانات التطبيق محليًا في IndexedDB داخل المتصفح، مع ترحيل تلقائي للبيانات القديمة من مفاتيح `localStorage` عند أول تشغيل بعد التحديث.
- تُسلسل عمليات الحفظ لتقليل احتمال الكتابة فوق تحديث أحدث بحفظ أقدم.
- عند عدم دعم IndexedDB أو تعذّر فتحه، يستخدم التطبيق `localStorage` كمسار احتياطي.
- يتضمن التطبيق PWA وService Worker لتخزين غلاف التطبيق والملفات التي تم تحميلها من نفس المصدر؛ يجب فتح التطبيق مرة واحدة مع اتصال قبل محاولة استخدامه دون اتصال.
- البيانات محلية لهذا المتصفح والجهاز ولا تتم مزامنتها تلقائيًا بين الأجهزة. لا تمسح بيانات الموقع أو المتصفح قبل تنزيل نسخة احتياطية والتحقق منها.
- هذه المرحلة لا تحوّل المشروع إلى تطبيق Android أصلي ولا تضيف SQLite؛ ذلك يتطلب مشروع Android/Flutter منفصلًا واختبارات ترحيل ومزامنة.

## النسخ الاحتياطي

من تبويب «النسخ» يمكن تنزيل JSON يشمل بيانات التطبيق، واستعادته بعد فحص البنية، أو تصدير سجل الفواتير إلى CSV. احفظ النسخ في مكان آمن؛ فقد تحتوي على معلومات مالية وبيانات عملاء. الاستعادة تستبدل بيانات المتصفح الحالي ولا تنشئ مزامنة بين الأجهزة.

## وظائف لم تكتمل بعد

تعدد الخزائن والعملات وأسعار الصرف، المخازن متعددة المواقع وتحويل المخزون، قارئ الباركود بالكاميرا، الطباعة الحرارية وBluetooth، صلاحيات المستخدمين، المزامنة السحابية والنسخ إلى Google Drive أو Telegram، وإصدار Android أصلي بقاعدة بيانات SQLite. هذه وظائف مراحل لاحقة وليست منجزة بمجرد ورودها في الخطة.

## تنبيه

المشروع قيد التطوير. راجع الأرصدة الافتتاحية والسياسات الضريبية والمرتجعات والتسويات مع محاسب قبل استخدامه في سجلات فعلية. لا تضع مفاتيح API أو كلمات المرور في مستودع GitHub.
